# IoT Smart Home Energy

Arduino-based IoT smart home system integrating solar energy management features, enabling real-time monitoring. Published in the International Journal of Innovative Research in Science, Engineering and Technology (IJIRSET), Dec 2018.

## Tech

`Arduino` `IoT` `Big Data Analytics` `Smart Home` `Energy Management`
